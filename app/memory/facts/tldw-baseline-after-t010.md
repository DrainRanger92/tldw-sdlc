# Базовая линия TLDW после T-010 (инкремент 002 закрыт)

Дата: 2026-11-27. Срез приложения после выполнения T-001–T-010 спеки
`specs/002-user-note-templates/` — текстовый сценарий пользовательского
шаблона заметки. Предыдущий срез — `tldw-baseline-after-t009.md`.

## Что умеет теперь

К MVP-сценарию (ссылка → транскрипт → конспект → `.md` для Obsidian)
добавилось управление шаблоном заметки в Telegram:

- `/template` и кнопка «Шаблон» открывают сценарий в любой момент: бот
  показывает «встроенный» шаблон либо пронумерованные разделы и тон
  пользователя, без вызовов LLM и YouTube;
- «Изменить» принимает одно текстовое сообщение 1–4000 символов обычными
  словами, LLM разбирает его в патч (разделы и/или тон) с учётом текущего
  шаблона, бот показывает кандидата без JSON и сохраняет только после
  «Сохранить»; «Исправить»/«Отмена» оставляют прежний шаблон;
- «Сбросить» с подтверждением удаляет пользовательский шаблон и возвращает
  встроенный; сброс идемпотентен и не вызывает LLM;
- активный шаблон применяется ко всем следующим ссылкам: разделы в заданном
  порядке и тон уходят в один вызов LLM, ответ валидируется против шаблона,
  заметка получает неизменный frontmatter из 7 полей; встроенный путь
  (без шаблона) остаётся прежним;
- шаблон хранится отдельно на Telegram user ID в
  `<DATA_DIR>/templates/<user_id>.json` (схема v1, атомарная запись,
  повреждённый/неизвестный файл → `WARNING` и встроенный шаблон);
  allowlist проверяется до показа/изменения/разбора, чужой шаблон не читается
  и не применяется;
- ошибки шаблона (разбор, лимиты, сохранение, сброс) дают русские тексты,
  известные сбои — `WARNING` с причиной, неизвестные — `ERROR` со
  стектрейсом; текст шаблона, тон и JSON кандидата в лог не пишутся
  (с оговоркой: открытый P2 ниже).

Лимиты — константы кода: 1–12 разделов, заголовок 1–80 символов, тон
0–1000, описание 1–4000, 1–10 пунктов в пользовательском разделе.

## Структура

```text
app/
  main.py, README.md, CHANGELOG.md
  tldw/  bootstrap.py, config.py, cli.py, logging_setup.py, errors.py, access.py, text.py
         handlers/ (link.py, template.py, router.py, __init__.py)
         services/ (note.py, summary.py, template.py)
         adapters/ (youtube.py, llm.py, resources/)
         storage/  (notes.py, templates.py, atomic.py)
  tests/ conftest.py, support.py, 25 test_*.py
```

Новые модули цикла 10: `services/template.py` (домен шаблона, лимиты,
`TemplateService`, слияние правки), `storage/templates.py` (JSON v1 на
пользователя), `storage/atomic.py` (общая атомарная запись для заметок и
шаблонов), `handlers/template.py` (`/template`, FSM, показ/подтверждение/
сброс), `text.py` (общий `one_line`). `adapters/llm.py` получил динамический
промпт и `parse_template`; `services/note.py` — `SectionKind`/`NoteSection`
и динамический рендер; `services/summary.py` — снимок шаблона и валидацию
пары «шаблон ↔ ответ».
