# Базовая линия TLDW после T-015

Дата: 2026-11-27. Исторический срез после цикла 15 (T-015 «Поведение
шаблона, заметки и голоса»). Версия в рабочей копии — **0.19.0**;
CHANGELOG и `__version__` обновляет VERSION-стадия после коммита (ожидаемо
0.20.0). Набор — **1081 тест** (+25), все офлайновые, `ruff check .` чист.

## Что умеет приложение

- Telegram-бот: ссылка на YouTube → транскрипт → конспект через LLM →
  `.md` для Obsidian; allowlist, лимит длительности, понятные ошибки.
- Пользовательский шаблон заметки: `/template` или кнопка «Шаблон»,
  1–12 разделов и тон 0–1000, разбор описания человеком через LLM, показ
  кандидата и сохранение только после «Сохранить»; шаблон хранится в
  `<DATA_DIR>/templates/<user_id>.json` (JSON v1).
- Голосовое описание: `handle_voice` → allowlist → состояние →
  `is_configured` → лимит 60 с → `BytesIO` → `to_thread` → распознавание
  одной попыткой; без `SPEECH_*` остаётся текстовый ввод, аудио и
  распознанный текст не пишутся в лог/`DATA_DIR`.
- Динамическая заметка сохраняет нативный формат встроенных разделов:
  «Таймкоды» — `- [MM:SS] текст`, «Цитаты» — `> текст` и `> — [MM:SS]`
  только при наличии таймкода.

## Что изменилось в T-015

- **Приватность лога:** несовпадение заголовка раздела пишет только
  `sections[index].heading не совпал с шаблоном` (ни заголовка шаблона, ни
  ответа LLM); отсутствие файла шаблона — `DEBUG`, битый JSON/схема/
  неизвестная `version` — `WARNING`.
- **Контекст ошибок:** `errors.describe_error`/`log_failure` принимают
  `unknown_message`; сценарий шаблона передаёт `MESSAGE_UNEXPECTED_TEMPLATE`
  во всех пяти точках сбоя. Известные ошибки по-прежнему отдают свой текст,
  старые вызовы — прежнее сообщение про видео.
- **Один источник пользовательских текстов:** `MESSAGE_AUDIO_TOO_LONG` в
  `errors.py`; его форматируют и обработчик, и `SpeechTooLongError`.
  `MAX_AUDIO_DURATION_SECONDS` имеет один публичный путь — `tldw.config`;
  реэкспорт из `adapters.speech`/`adapters.__init__` удалён.
- **Симметрия ввода:** проверка `extract_first_url` перенесена в общий
  `_present_description`; надиктованная ссылка получает ту же подсказку,
  что текстовая, LLM не вызывается. `StateFilter(*_DESCRIPTION_STATES)`
  вместо второго перечисления состояний.
- **Косметика T-005:** `_positive_int(value, name)` с русскими именами
  лимитов; `join_transcript` округляет секунды (`round`); `_string_items`
  отвергает нестроковые элементы вместо `str(item)`; `process` снимает
  пробелы один раз (`clean_url` для `fetch` и `source`).
- **Документация:** обновлены ADR-015/ADR-016 (лимит/импорт/симметрия),
  README (путь импорта константы), скилы `shared-helpers` и
  `adapter-boundary`; добавлены ADR-020/ADR-021 и
  `facts/t015-debt-audit.md`.

## Контракты и границы

- Новых зависимостей, env-переменных, FSM-состояний и второго сценария нет.
- Внешний контракт `SummaryService.process`, формат `.md`, встроенный путь
  и тексты по умолчанию не менялись; динамический путь получил нормализацию
  таймкода/цитаты.
- Read-only ревьюер по-прежнему не может прогнать `pytest`; в цикле 15 —
  впервые 0 исполненных тестов (3 попытки), зелёность подтверждена LEARN.
- Защищённые пути не затронуты; правка `specs/003-review-debt/tasks.md` —
  артефакт оркестратора.
