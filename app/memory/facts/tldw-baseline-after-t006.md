# Базовая линия TLDW после T-006

Дата: 2026-11-26. **Исторический срез** после шестого цикла: Telegram-сценарий
подключён к сервису конспекта. Актуальный срез —
`tldw-baseline-after-t007.md` (309 тестов, allowlist). Предыдущий —
`tldw-baseline-after-t005.md` (257 тестов); на момент этого среза было
**282 теста**.

## Что появилось

- **`app/tldw/handlers/link.py` (169 строк).** `extract_first_url(text)` —
  первая ссылка из текста: `http(s)://`/`www.` на любой домен и YouTube-ссылки
  без схемы (`youtube.com/watch`, `youtu.be`, `/shorts/`), хвостовая
  пунктуация отбрасывается, почта и обычный текст ссылкой не считаются.
  `LinkHandler` — тонкий обработчик: на ссылку сразу отвечает «✅ Принял
  ссылку.», запускает обработку фоновой задачей, шлёт «⏳ Обрабатываю видео…»,
  уводит синхронный `SummaryService.process` в `asyncio.to_thread`, проверяет
  сохранённый файл, отправляет `.md` документом с именем из шаблона и пишет
  «✅ Готово.». Текст без ссылки получает подсказку с примером YouTube-ссылки.
  Ошибки сервиса — `log.exception` + общее «Не удалось обработать видео.
  Попробуйте позже.» (временная точка для T-008). Фоновые задачи учитываются
  в множестве, `wait_idle()` позволяет дождаться их завершения.
- **`handlers/router.py`.** `create_router(service)` создаёт корневой
  `Router(name="tldw")` и регистрирует `LinkHandler` на `F.text`.
- **`handlers/__init__.py`.** Реэкспорт `create_router`, `LinkHandler`,
  `SummaryProcessor`, `extract_first_url` и шести текстов сообщений.
- **`bootstrap.py`.** `build_application(settings, *, summary_service=None)`
  собирает `Bot` (HTML parse mode), `Dispatcher`, сервис на реальных адаптерах
  (`build_summary_service`, ленивый импорт адаптеров), подключает роутер,
  создаёт `DATA_DIR`; `Application.run()` — polling, `close()` — закрытие
  сессии бота. Параметр `summary_service` — шов для тестов без сети.
- **Тесты.** `tests/test_link_handler.py` (443 строки, 21 кейс): порядок
  четырёх ответов, файл существует в момент `SendDocument`, текст без ссылки,
  первая из нескольких ссылок, не-YouTube ссылка доходит до сервиса, вызов
  сервиса в рабочем потоке, живой event loop, ошибка сервиса, отсутствующий
  файл, подключение роутера, 10 параметризованных кейсов извлечения ссылки,
  интеграционный кейс с настоящим `SummaryService` и `tmp_path`. Плюс тест
  совпадения `tldw.__version__` с `pyproject.toml`.
- **Релизные метаданные.** Версия 0.9.0 в `pyproject.toml` и
  `tldw/__init__.py`, запись в `CHANGELOG.md`.

## Чего ещё нет (на момент среза)

- **T-007 (allowlist).** Обработчик принимает любого пользователя; проверки
  доступа до парсинга ссылки и вызовов адаптеров нет.
- **T-008 (понятные ошибки).** Все сбои сводятся к общему сообщению; тексты
  для «не YouTube», «нет субтитров», «слишком длинное видео», «AI не ответил»
  не сделаны; `log.exception` пишет полный URL.
- **T-009 (E2E + README).** Сквозного теста «сообщение → `.md`» на всех
  фейках и инструкции запуска в README приложения нет. README репозитория
  описывает оркестратор, а не запуск бота.
- Ограничения обработчика: нет отмены фоновых задач при остановке, нет
  лимита параллелизма/дедупликации ссылок, `_LINK_RE` без левой границы,
  флаки-риск в тесте event loop — подробно в `t006-review-issues.md`.
- Долг прошлых циклов: пустой транскрипт не отвергается сервисом,
  `httpx.InvalidURL`/`RuntimeError` мимо `LLMError`, три копии `_one_line`.
