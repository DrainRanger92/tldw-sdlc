# ADR-001: Конфигурация TLDW — только env, fail-fast на старте

- Статус: принято
- Дата: 2026-11-26
- Цикл: 1, задача T-001

## Контекст

Приложению нужны токен бота, ключ и модель LLM, allowlist, порог длительности
видео, каталог данных и уровень логов. Секреты не должны попадать в код,
фикстуры, логи и сообщения об ошибках. Тесты и гейты обязаны работать без сети
и без реальных токенов, а при неполной конфигурации пользователь должен получить
понятную ошибку при старте, а не падение в рантайме.

## Решение

- Единственный источник настроек — переменные окружения. `app/.env` только
  подставляет значения, которых нет в реальном env; реальный env всегда
  приоритетнее.
- `load_settings(environ)` собирает frozen dataclass `Settings` и валидирует
  значения; при ошибке поднимается `ConfigError` с именем переменной и
  подсказкой, но без значения секрета.
- Обязательные переменные: `TELEGRAM_BOT_TOKEN`, `LLM_API_KEY`, `LLM_MODEL`.
  Остальные имеют безопасные дефолты; полный список — `ALL_ENV_VARS`,
  `REQUIRED_ENV_VARS`, `OPTIONAL_ENV_VARS`.
- Секреты помечены `field(repr=False)`, чтобы случайный `repr(settings)` не
  раскрыл токен.
- `.env` разбирается собственным небольшим парсером (комментарии, кавычки,
  `export`, inline-комментарии), без зависимости от `python-dotenv`.
- CLI даёт `--check-config` (валидация и сборка без polling, код 2 при ошибке
  конфигурации) и `--env-file` для явного файла.

## Альтернативы

- `pydantic-settings` — удобно, но лишняя зависимость и более тяжёлый старт
  для каркаса MVP.
- `python-dotenv` — ещё одна зависимость; нужен контроль приоритета env над
  файлом и предсказуемые ошибки, поэтому парсер написан явно.
- Ленивое чтение настроек в момент первого запроса — ошибки конфигурации
  всплывали бы в рантайме, а не на старте; отвергнуто.

## Последствия

- Новую переменную нужно добавить в `ALL_ENV_VARS` и в `app/.env.example`;
  тест `test_packaging.py` сверяет их состав.
- Адаптеры и сервисы получают `Settings` явно, глобального конфига нет —
  тесты передают словарь env напрямую.
- Конфигурация неизменяема в рантайме; для смены настроек нужен перезапуск.
- Парсер `.env` поддерживает только плоские `KEY=VALUE`; этого достаточно
  для MVP, но сложные форматы (многострочные значения) не поддерживаются.
