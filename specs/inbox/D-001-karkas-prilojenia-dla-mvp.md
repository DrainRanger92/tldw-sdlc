## Описание
Создать каркас приложения TLDW и наполнить им `specs/001-mvp/` (сейчас `spec.md`,
`plan.md`, `tasks.md` — пустые заготовки), чтобы из него можно было брать задачи
на фичи MVP из `specs/product.md`.

Каркас по правилам `app/AGENTS.md`: пакет `app/tldw/` со слоями
`handlers/` (Telegram), `services/` (транскрипт, конспект, шаблон заметки),
`adapters/` (YouTube, LLM), `storage/`; точка входа `app/main.py`; конфиг и
секреты (`TELEGRAM_BOT_TOKEN`, ключ LLM) только из env; `app/pyproject.toml`
со стеком Python 3.11+ / aiogram 3 / pytest / ruff; тесты без сети и токенов.

Границы инкремента: каркас должен доводить реальную ссылку на YouTube до
готового `.md`-файла в чате (сквозной путь «ссылка → транскрипт → LLM →
заметка», без заглушек вместо интеграций) и при этом проходить `pytest -q` +
`ruff check .`.

Решения по объёму (из уточнения):
- Нужен сразу рабочий сквозной путь, а не скелет с заглушками адаптеров.
- Allowlist по Telegram user ID и понятные ошибки (не YouTube / нет субтитров /
  слишком длинное видео / AI не ответил) входят в этот инкремент, а не отдельными
  задачами.
- Слишком длинное видео: отказ с понятным сообщением пользователю (без частичной
  заметки), порог задаётся конфигом; значение по умолчанию — на усмотрение
  команды (ориентир ~2 часа).
- Заметка — по полному шаблону из `specs/product.md`; исходный шаблон и промпт
  живут в коде/ресурсах пакета, а не в env.

## Открытые вопросы
- [x] Входит ли в каркас сквозной рабочий путь «ссылка → транскрипт → LLM → .md»,
  или в этом инкременте нужен только запускаемый скелет с заглушками адаптеров,
  а реальные интеграции — отдельными задачами?
  **Ответ:** нужен уже рабочий путь — не только скелет.
- [x] Какая планка у сквозного пути в этом инкременте: достаточно, чтобы одна
  реальная ссылка доходила до `.md` по полному шаблону из `product.md`, а allowlist
  и понятные ошибки (нет субтитров / слишком длинное видео / не YouTube / AI не
  ответил) шли отдельными задачами? Или allowlist и обработку ошибок закладываем
  уже в каркас?
  **Ответ:** закладываем сразу — allowlist и понятные ошибки входят в этот
  инкремент, а не отдельными задачами.
- [x] Что делаем со «слишком длинным видео»: отказываем с понятным сообщением

  части и всё равно отдаём заметку?
  **Ответ:** на усмотрение команды — отказ с понятным сообщением, порог
  (длительность видео) из конфига, дефолт ~2 часа.
