### T-013: Типизированные ошибки LLM и речи, полная валидация URL и пустой транскрипт
- тип: app
- статус: done
- зависит: —
- размер: M

**Описание**
Закрыть P1 T-004/T-005 и P2 T-011: `httpx.InvalidURL` и `RuntimeError`
отсутствующего ресурса промпта выходят мимо `LLMError`; `SpeechAdapter._make_client()` стоит вне `try`; `load_settings` проверяет только схему
`*_BASE_URL`; `SummaryService.process` не отвергает пустой транскрипт;

`t005-review-issues.md`, `t011-review-issues.md`,

закрыть с доказательством. Контракт ошибок должен быть один: внешний сбой —
`UserFacingError`-наследник с понятным русским текстом, а не сырое исключение
httpx/Python; битый URL — `ConfigError` на старте.

**Критерии приёмки**
- [ ] Проведён аудит перечисленных источников; в отчёте задачи таблица «пункт → актуален/устарел/процессный → доказательство»; устаревшие закрыты без отдельной задачи и без правки кода
