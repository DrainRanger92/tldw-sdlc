Название проекта - **TLDW** Too Long; Didn't Watch. Понятная аббревиатура
# TLDW
Telegram-бот, который превращает образовательное видео с YouTube
в структурированную заметку для Obsidian — без пересмотра и ручного конспектирования.
## Vision
Любое образовательное видео — лекция, туториал, разбор, интервью —
должно превращаться в аккуратную заметку в моём Obsidian-vault
за время, пока я пью кофе.
Я не хочу пересматривать видео, чтобы вспомнить «о чём оно было».
Я не хочу вручную выписывать тезисы и таймкоды.
Я хочу отправлять боту ссылку и получать готовый `.md`-файл,
который можно сразу положить в vault и найти через `[[ссылку]]`.
## Elevator pitch
Отправил ссылку на YouTube → через 20–40 секунд получил `.md`-файл
с frontmatter, TL;DR, ключевыми идеями, таймкодами и тегами —
готовый к вставке в Obsidian.
## Target user
**Primary (я сам).** Разработчик / исследователь / студент, который:
- ведёт Obsidian как second brain;
- ценит приватность и контроль над данными;
- готов один раз настроить бота, чтобы дальше не думать.
**Secondary (потенциально).** Небольшой круг друзей/коллег
с похожим workflow — если проект окажется полезным, можно открыть
доступ по allowlist.
## Solution
Telegram-бот `@tldw_bot`:
1. Принимает ссылку на YouTube.
2. Достаёт транскрипт (субтитры или автоматические субтитры).
3. Отправляет транскрипт в LLM с жёстким промптом на структуру.
4. Возвращает пользователю `.md`-файл с конспектом.
5. (опционально, v2) сохраняет копию транскрипта в vault и обновляет
   индекс.
## Key features (MVP)
- [ ] Приём ссылки на YouTube через Telegram.
- [ ] Извлечение транскрипта (`youtube-transcript-api`, fallback `yt-dlp`).
- [ ] Генерация конспекта через LLM.
- [ ] Формат `.md`, совместимый с Obsidian, по Шаблону:
  - YAML frontmatter: `title`, `source`, `channel`, `duration`,
    `date`, `tags`, `status: processed`;
  - `## TL;DR` — 3–5 предложений;
  - `## Ключевые идеи` — 5–10 пунктов;
  - `## Таймкоды` — по главам/смысловым блокам;
  - `## Цитаты` — 2–3 яркие цитаты с таймкодами;
  - `## Что проверить` — открытые вопросы и follow-up.
- [ ] Ответ асинхронный: «принял → обрабатываю → готово».
- [ ] Понятные ошибки: нет субтитров, слишком длинное видео,
  не YouTube, AI не ответил.
- [ ] Ограничение доступа по Telegram user ID (allowlist).
- [ ] Секреты через `.env`, логирование ошибок.
